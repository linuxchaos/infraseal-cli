# MCPvia

MCPvia is InfraSeal's Evaluation Orchestration Engine. It is not merely a command dispatcher for scanners.

In the CLI MVP, MCPvia owns:

1. Workload classification.
2. Scan profile selection.
3. Input and evidence resolution.
4. Runtime selection and fallback.
5. Evaluator orchestration.
6. Native offline controls.
7. Finding normalization.
8. Duplicate finding correlation.
9. Trust score calculation.
10. ISO/IEC 42001 readiness mapping.
11. Prioritized recommendation generation.
12. JSON, Markdown, HTML, and PDF report generation.

The stable finding and report schemas are designed to support repository pull request gates, policy review, customer-managed runtime checks, and future trusted evaluation environments.
