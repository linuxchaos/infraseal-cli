# AI Vendor Review

Provider dependencies must be reviewed before production use. The review records data shared with the provider, retention terms, training-use restrictions, model/version ownership, logging controls, security posture, incident-notification route, and exit criteria.

The sample workload is configured for local deterministic evaluation. If a hosted model provider is added, the data owner and AppSec reviewer must approve the provider terms and confirm that sensitive production exports are redacted before external evaluation.
