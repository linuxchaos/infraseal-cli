# AI Incident Response

AI incidents include harmful guidance, materially incorrect answers, suspected data leakage, credential exposure, unauthorized tool activity, or infrastructure exposure affecting AI workload data. The first responder must preserve prompts, retrieved context, answer output, scan reports, and relevant logs.

Containment may include disabling the agent route, removing affected evidence, revoking credentials, narrowing permissions, or rolling back infrastructure changes. Re-release requires root-cause notes, updated regression tests, risk-owner approval, and a clean focused scan for the affected category.
