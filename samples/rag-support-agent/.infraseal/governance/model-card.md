# Model Card

The sample workload represents a customer-support RAG assistant. It is intended to answer policy questions from approved knowledge-base content and escalate uncertain requests to a human support workflow. It is not approved for account modifications, eligibility decisions, legal advice, or autonomous external communications.

Known limitations include retrieval misses, unsupported answer claims, prompt-injection attempts embedded in retrieved text, and overly broad agent tool permissions. Release evidence must include test cases for grounding, prompt injection, PII leakage, unsafe output, and agent side-effect approval.
