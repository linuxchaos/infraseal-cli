# AI Change Management

Material changes require re-evaluation before deployment. Material changes include system prompt edits, retrieval source additions, model/provider changes, agent skill permission changes, tool integrations, dependency upgrades, and Terraform changes affecting public access, secrets, databases, or IAM policy.

Every release record must link the commit, InfraSeal report, reviewer approval, unresolved findings, and risk-acceptance decision. Emergency changes can deploy only with named owner approval and must receive post-deployment review within one business day.
